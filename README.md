# Mata Viva — Atlantic Forest Impact Fund Platform

Collaborative business plan and financial modelling tool for the Mata Viva founding team.

## What's inside

| File | Purpose |
|------|---------|
| `index.html` | The entire platform — single self-contained file |
| `DEPLOY.md` | Step-by-step guide to go live on GitHub Pages + Supabase |

## Features

- **Overview** — live financial metrics + charts (conservative / base / aggressive scenarios)
- **Fund economics** — two financial models: full stack (carbon + credits) and no-credit (agroforestry + PES only)
- **Business model** — end-to-end value flow diagram
- **Business plan** — seven editable sections (Problem, Solution, Market, Differentiation, GTM, Team, Risks)
- **Priority regions** — Atlantic Forest phased rollout map
- **Change log** — every edit tracked with author + timestamp

## Quick start

1. Follow `DEPLOY.md` to set up Supabase (free) and deploy to GitHub Pages (free)
2. Replace the two placeholder values in `index.html` with your Supabase credentials
3. Share the GitHub Pages URL with co-founders

## Tech stack

Plain HTML + CSS + JavaScript. No framework, no build step.
Chart.js for visualisations. Supabase REST API for shared persistence.
